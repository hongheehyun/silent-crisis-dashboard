SECTION 04 · A1 성공요인

GDP 제거 후 드러난 진짜 성공 요인

비교 변수에서도 GDP 효과를 제거(잔차화)했을 때, 젠더·보건·교사가 독립 성공요인으로 확인됩니다.

방법 A: 변수 잔차화 후 Cohen's d

● p<0.05 유의   ● p<0.10 경향   ● 비유의

방법 B: GDP 분위별 내부 비교

p<0.10 유의·경향 변수만 표시. 색상 = Cohen's d 크기

💡
핵심 인사이트 10대 출산율(d=−0.92)이 1위, 의사 수(d=+0.78)·교사-학생 비율(d=−0.68)·여성 조혼율(d=−0.63)·유아 사망률(d=−0.54) 순. 반면 교육지출(p=0.49)과 거버넌스(p=0.97)는 A1에서 비유의 — 거버넌스는 A2(회귀 모델)에서 GDP 통제 후 독립 효과가 확인됩니다.
SECTION 05 · A2 분석

정책 효율성 역설 — "돈이 아니라 거버넌스"

교육 예산 지출은 단독으로는 효과가 없습니다. 거버넌스가 GDP와 독립적으로 Learning Poverty를 낮추는 핵심 변수입니다.

+0.08
교육지출 β
p=0.97 — 통계적으로 무의미
−16.6
거버넌스 β
p<0.001 — 강력히 유의
0.618
모델 R²
GDP+거버넌스+교육지출 통합

OLS 회귀 계수 비교

표준화 β (GDP 통제 후). 빨강=유의(p<0.05), 회색=비유의

부트스트래핑 신뢰구간 (B=500)

95% CI. 0을 포함하지 않으면 효과가 안정적으로 유의함

💡
핵심 인사이트 거버넌스(WGI) 1 표준편차 상승 → Learning Poverty 평균 16.6%p 감소 (GDP 통제 후). 교육 예산 지출은 어떤 거버넌스 수준에서도 단독으로는 효과가 없음 (β=+0.08, p=0.97). "얼마나 쓰는가"보다 "얼마나 잘 운영하는가"가 결정적입니다.
