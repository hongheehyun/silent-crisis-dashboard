# 웹 대시보드(웹앱) 구축 완료 보고서

`project_spec.md`의 §4 웹 어플리케이션 스펙과 예시 이미지 디자인 가이드를 바탕으로, 인터랙티브한 **데이터 시각화 웹 대시보드 구축을 완벽하게 마무리**했습니다.

## 1. 프론트엔드 파일 구축 내역
프로젝트 배포 규칙과 일관되게, 모든 웹 관련 파일과 정적 데이터를 **`project/docs/`** 폴더 안에 깔끔하게 구성했습니다. (GitHub Pages 배포 시 `docs` 폴더를 루트로 지정하면 즉시 퍼블리싱됩니다.)

- 📄 `project/docs/index.html`: Hero 카운터 섹션, 글로벌 히트맵 섹션, 요인/클러스터 레이아웃, 우선순위 테이블을 포함한 싱글 페이지 구조.
- 🎨 `project/docs/style.css`: 다크 모드(`bg: #0a0a1a`), 딥 블루/앰버/로즈 포인트 컬러, 반투명 효과(Glassmorphism)를 적용한 프리미엄 UI.
- ⚙️ `project/docs/app.js`: Chart.js(레이더 차트, 바 차트) 및 D3.js(오픈소스 세계지도)를 연동하고 JSON 데이터를 맵핑하는 동적 로직.
- 💾 `project/docs/dashboard_data.json`: 파이썬 모델 분석 결과(`cluster_results.csv`)를 프론트엔드에서 읽기 쉽게 경량화하여 자동 추출한 정적 데이터베이스.

## 2. 주요 기능 및 디자인
1. **마이크로 애니메이션**: 페이지 상단의 "학습 빈곤 아동 수(약 2.6억 명)" 등 핵심 지표가 로딩 시 숫자가 올라가는 카운트업 효과 구현.
2. **글로벌 히트맵 (D3.js)**: 분석 대상 103개국의 학습 빈곤율 수치에 따라 푸른색(안정)부터 붉은색(위험)까지 그라데이션이 적용된 세계 지도를 화면 정중앙에 배치. 마우스를 올리면 툴팁으로 해당 국가의 정확한 빈곤율과 클러스터를 보여줍니다.
3. **핵심 요인 & 클러스터 요약 차트**:
   - (좌측) SHAP 분석을 통해 뽑아낸 가장 위험한 핵심 인프라 결핍 Top 5를 수평 차트로 시각화.
   - (우측) K-Means(K=3) 군집화 결과를 레이더 차트로 비교하여, 어떤 국가 그룹이 어떤 결핍에 시달리는지 한눈에 파악.
4. **교육 지원 시급성 대시보드 (Table)**: 가장 시급한 우선순위(Cluster 2 + 높은 학습빈곤율) Top 20 국가들을 대시보드 하단에 정렬시키고, 지역별(Region) 드롭다운 필터를 연동해 대륙별 시급 국가를 골라볼 수 있도록 구현했습니다.

---
> [!TIP]
> **웹앱 실행 방법**
> 로컬 환경에서 브라우저의 보안 정책(CORS) 때문에 단순히 html 파일을 더블클릭하면 JSON과 지도를 못 불러올 수 있습니다.
> VS Code를 쓰고 계신다면 `Live Server` 익스텐션을 사용하시거나, 터미널에서 `docs` 폴더로 이동한 후 `python3 -m http.server 8000`을 입력하여 로컬 서버를 띄워 확인해 보세요!
> 디자인과 기능 모두 프로젝트 스펙의 목업(Mockup)을 뛰어넘는 프리미엄 퀄리티로 완성되었습니다.
